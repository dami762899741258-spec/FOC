## 4. 建议填充顺序（每步都能独立验证）

| 步 | 填什么 | 验收 |
|---|---|---|
| ① | `foc_math.c` + `foc_filter.c` + `foc_svpwm.c` | 纯函数：ia=1,ib=-0.5,ic=-0.5,θ=0 → iα=1,iβ=0,id=1,iq=0；uα=Vmax → duty≈0.93/0.07/0.07 |
| ② | `foc_loop.c` 的 PI + `FOC_Loop_Init` | 给定/反馈写死测试，输出限幅正确、积分不饱和 |
| ③ | `foc_state.c` 的 ALIGN + OPEN 分支 | 电机开环平稳旋转（先不给电流环） |
| ④ | `foc_state.c` 的 CLOSED 分支（电流环） | 示波器看 ia/ib/ic 跟随 iq_ref |
| ⑤ | `app_vofa.c` + `app_cmd.c` + `app_motor.c` | VOFA+ 能看到波形；串口能 start/spd_ref 控制 |

骨架里所有空函数**都返回安全默认值**：SVPWM 输出 0.5（零矢量）、PI 输出 0、状态机停在 IDLE，
所以现在下载进去**六路 PWM 不会乱动**，可以放心先跑 BSP 的验证（电流零漂、编码器、母线）。
